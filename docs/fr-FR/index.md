## 🤝 Contribuer à la traduction

Vous souhaitez aider à traduire la documentation ? Génial !

1. Consultez le [Guide de contribution](/CONTRIBUTING.fr.md)
2. Vérifiez le glossaire dans `docs/.i18n/glossary.fr-FR.json` pour la terminologie cohérente
3. Soumettez une Pull Request avec vos traductions

## 📝 Note sur la traduction

Cette traduction suit le glossaire officiel français pour assurer la cohérence :
- **Gateway** → Passerelle
- **Skills** → Compétences
- **Channels** → Canaux
- **Agent** → Agent
- **Session** → Session

Pour la liste complète des termes, voir `docs/.i18n/glossary.fr-FR.json`.
