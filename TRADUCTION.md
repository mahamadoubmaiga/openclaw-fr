Les fichiers traduits sont organisés dans `docs/fr-FR/` selon la même structure que la documentation anglaise :

```
├── start/                # Guides de démarrage
├── help/                 # Documentation d'aide

```

## 🤝 Contribuer

Vous souhaitez aider à traduire ? Super !

1. Consultez le fichier [CONTRIBUTING.fr.md](CONTRIBUTING.fr.md)
2. Vérifiez le glossaire dans `docs/.i18n/glossary.fr-FR.json`
3. Traduisez en suivant la structure existante
4. Soumettez une Pull Request

### Priorités de traduction

Pour contribuer efficacement, concentrez-vous sur :

1. **Guides d'installation restants** (docs/install/)
2. **Guides de démarrage** (docs/start/)
3. **Documentation d'aide** (docs/help/)
